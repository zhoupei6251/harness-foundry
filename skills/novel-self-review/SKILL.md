# Novel Self-Review — 写作自评机制

> 轻量级自检流程，5 维标准。writer 写完后先自我审查，达标才提交 reviewer，减少返修次数。

## 激活条件

- Writer 完成章节初稿
- 提交给 reviewer 之前

## 自评流程

```
writer 写初稿
  → self-review 自检（5项）
    → 有问题 → writer 修正（循环，最多 2 次修正）
    → 无问题 → 输出给 reviewer
```

### 循环机制

自检发现问题 → 标注问题 → 交回 writer 修正 → 再次自检
最多修正 2 轮。2 轮后仍有问题，输出带标记的报告，交由 reviewer 判定。

## 5 维自检标准

| 维度 | 检查项 | 通过标准 | 不通过处理 |
|------|--------|----------|------------|
| **字数** | 正文总字数 | ≥2000 字 | 扩充内容或合并短章 |
| **钩子** | 章节结尾悬念 | 有具体悬念（信息差/反转/冲突），非套话 | 强化结尾，制造追读欲 |
| **AI痕迹** | 陷阱清单表达 | 无 #1-15 类 AI 套路化表达 | 替换为具体描写 |
| **人物一致** | 对话符合度 | 对话符合人物设定，无声音趋同 | 调整对话风格 |
| **伏笔** | 新伏笔登记 | 新埋伏笔须记录到伏笔 DAG | 写入 MEMORY.md 伏笔表 |

### 陷阱清单（自检重点）

**AI 痕迹 (#1-15)**：
- #8: "眼中闪过一丝" → 用具体肢体语言替代
- #9: "嘴角勾起一抹" → 用更自然的表情变化
- #10: "深吸一口气" → 直接写行动或心理
- #13: "不是A，不是B，而是C" → 直接说"是C"
- #15: "仿佛""似乎"过度 → 直接陈述

**章节结构 (#34-40)**：
- #35: 章节末尾没有钩子 → 每章结尾留悬念

## 自检输出格式

### 通过报告

```markdown
## 自检报告 — 第X章

### 检查结果
| 维度 | 结果 | 备注 |
|------|------|------|
| 字数 | ✅ 通过 | 约 3200 字 |
| 钩子 | ✅ 通过 | 第 412 行：XXX 留下悬念 |
| AI痕迹 | ✅ 通过 | 无陷阱命中 |
| 人物一致 | ✅ 通过 | 对话符合人物设定 |
| 伏笔 | ✅ 通过 | 新增伏笔已登记 |

### 伏笔记录（如有）
- [伏笔] XXX（第 156 行）→ 待回收于第 N 章

### 结论: PASS — 提交 reviewer
```

### 未通过报告

```markdown
## 自检报告 — 第X章

### 检查结果
| 维度 | 结果 | 问题 |
|------|------|------|
| 字数 | ✅ 通过 | 约 2100 字 |
| 钩子 | ❌ 未通过 | 结尾平淡，无悬念 |
| AI痕迹 | ❌ 未通过 | 第 45/112 行含"眼中闪过一丝" |
| 人物一致 | ✅ 通过 | 对话符合设定 |
| 伏笔 | ✅ 通过 | 无新伏笔 |

### 问题详情
1. [钩子] 第 412-418 行：结尾直接总结，无悬念
   - 建议：添加信息差悬念（主角已知但读者不知的危险）
2. [AI痕迹] 第 45 行："眼中闪过一丝决然"
   - 建议：替换为"他攥紧剑柄，指节泛白"
3. [AI痕迹] 第 112 行："眼中闪过一丝慌乱"
   - 建议：替换为"脚步后退半步，撞翻了桌上的茶盏"

### 结论: FAIL — 返回 writer 修正（第 1 轮/共 2 轮）
```

### 修正后仍有问题

```markdown
## 自检报告 — 第X章（第 2 轮）

### 检查结果
| 维度 | 结果 | 问题 |
|------|------|------|
| 字数 | ✅ 通过 | |
| 钩子 | ❌ 未通过 | 仍无有效悬念 |
| AI痕迹 | ✅ 通过 | 已修正 |
| 人物一致 | ✅ 通过 | |
| 伏笔 | ✅ 通过 | |

### 问题详情
1. [钩子] 第 412-418 行：仍未解决
   - 原因：修改方案未有效执行
   - 建议 reviewer 介入判定

### 结论: FAIL — 提交 reviewer 特殊判定（单章已达修正上限）
```

## 与 traps-archive 联动

自检仅覆盖 **AI 痕迹（#1-15）** 和 **章节结构（#34-40）**，其余陷阱由 reviewer 负责。

## 与伏笔 DAG 联动

- 新伏笔：写入 MEMORY.md 伏笔表
- 格式：`[伏笔] 内容（第 N 行）→ 待回收于第 M 章`
- 自检时确认伏笔登记完整性

## 禁止

- ❌ 自检通过但有明显问题（遗漏 Critical 问题）
- ❌ 跳过字数统计
- ❌ 不检查伏笔登记
- ❌ 捏造通过结果
- ❌ 自行润色（润色由 humanizer 负责）

## 1. 场景模板（Scene Templates）

### 1.1 开场场景：建立世界观 + 引出主角

#### 适用场景
- 新书开篇第一章
- 新卷/新篇章开启
- 新场景首次出现时

#### 结构
1. **环境勾勒**（1-2段）：用感官细节建立氛围，暗示时代/地域/势力格局
2. **异常事件**：用打破日常的小事件引出主角，让读者产生好奇
3. **主角登场**：通过行动而非旁白展示主角性格，给出"钩子信息"

#### 示例
```
灰蒙蒙的天压得很低，江南水乡的青石板路被细雨润得发亮。

"让开让开！"一匹枣红马从巷口冲出，马上之人锦衣华服，腰间玉佩叮当作响。

人群四散之际，唯有一个少年站在原地，不闪不避。他衣衫破旧，右手却稳稳按在腰间——那里藏着一柄断刃。

"找死？"马蹄扬起的泥水溅了他一脸。

少年抬眼，声音平静得可怕："你的马，受了惊。"

马上之人愣了一瞬，低头看去——马眼赤红，口吐白沫，正是狂化之兆。
```

#### 变体
- **仙侠开场**：以异象/天劫/秘境开启引出
- **都市开场**：以身份反差（豪门弃子/隐藏大佬）引出
- **末世开场**：以生存危机/资源争夺引出

---

### 1.2 日常场景：展示角色性格

#### 适用场景
- 章节中段过渡
- 人物关系建立期
- 节奏缓冲/情绪休整

#### 结构
1. **日常行为**：通过吃穿住行展示角色习惯
2. **细节暗示**：用小物件/小动作暗示隐藏设定
3. **冲突伏笔**：日常对话中埋入后续冲突的种子

#### 示例
```
"老板，老样子。"

张铁山在面摊角落坐下，解下背后那柄用布包裹的长刀，放在桌角——刀柄朝外。

老板娘瞥了一眼，熟练地下了一碗阳春面，加了两勺辣子。

"今天怎么早？"

"有事。"张铁山接过面，忽然问，"你家闺女，最近有没有收到什么奇怪的信？"

老板娘的手顿了一下，旋即若无其事地擦着桌子："问这个干嘛？"

"没什么。"张铁山低头吃面，眼角余光却始终没离开街角那个穿灰袍的身影。
```

#### 变体
- **师徒日常**：以教导/互动展示传承关系
- **情侣日常**：以默契/拌嘴展示情感深度
- **敌对日常**：以试探/暗讽展示紧张关系

---

### 1.3 冲突场景：升级矛盾

#### 适用场景
- 中期矛盾激化
- 势力对决
- 资源/利益争夺

#### 结构
1. **矛盾起源**：明确冲突的导火索
2. **双方立场**：用对话/行动展示各自诉求
3. **升级事件**：引入第三方/突发事件打破平衡
4. **悬念收尾**：留下未解决的张力

#### 示例
```
"三七分成，少一个子儿都不行。"赵四把契约拍在桌上，嘴角带着笑。

李掌柜额头冒汗："赵爷，这批药材本钱就要五千两，三七分我们只能拿三百两利润..."

"那是你们的事。"赵四站起身，目光扫过铺子里的人，"听说你们东家和官府有来往？"

门外忽然传来马蹄声。

一个捕快翻身下马，高声道："哪位是李掌柜？有人告你们贩卖私盐——"

赵四的笑容僵住了。这条罪名，正是他准备扣在李家头上的。

"有意思。"他低声说，"倒要看看是谁抢先了。"
```

#### 变体
- **升级冲突**：从言语冲突→肢体冲突→生死对决
- **多方混战**：引入第三方打破两方对峙
- **内鬼反转**：冲突中被盟友背刺

---

### 1.4 高潮场景：情绪爆发

#### 适用场景
- 章节/卷册最高潮
- 关键决战后
- 情感宣泄点

#### 结构
1. **压力积累**：用连续短句/紧迫动作增加紧张感
2. **爆发点**：主角行动或关键揭示
3. **余波**：情绪宣泄后的短暂平静或新问题

#### 示例
```
剑光如雪。

三年前的那一夜，也是这样的雪。

"为什么？"林晚棠的声音在风雪中嘶哑，"父亲待你如亲子，林家有何对不起你——"

"待我如亲子？"沈墨染笑了，笑声凄厉，"他夺我母亲性命，毁我全家根基，却把我留在身边当一条狗！"

他一剑刺出，林晚棠侧身闪避，肩头仍被划开一道血痕。

"这三年，我每叫你一声师兄，每替你挡一剑，心里想的都是——"

他的剑停在林晚棠咽喉三寸处。

"——今日，该如何杀你。"

雪落无声。剑锋映着月光，冷如三年前那个血色黄昏。
```

#### 变体
- **战斗高潮**：以招式/力量对决为核心
- **情感高潮**：以真相揭示/关系崩溃为核心
- **智谋高潮**：以翻盘/逆袭为核心

---

### 1.5 过渡场景：承接 + 铺垫

#### 适用场景
- 章节间衔接
- 场景转换
- 情绪过渡

#### 结构
1. **收束前情**：用一句话或一个动作呼应前文
2. **时间/空间跳跃**：简略过渡不重要的过程
3. **新信息植入**：为下一段情节埋下伏笔

#### 示例
```
那一夜，林晚棠在屋顶坐到天明。

第二天清晨，她收拾行囊，告别师父，下山。

三个月后，江湖上多了一个传闻：销声匿迹十年的"血衣侯"重现江湖，手中一柄银蛇剑，已连败十七名高手。

没人知道，这个血衣侯，是个女子。

更没人知道，她要找的第一个人，姓沈。
```

#### 变体
- **时间跳跃**：用季节/节气过渡
- **空间跳跃**：用路途见闻过渡
- **人物跳跃**：用旁观者视角过渡

## 2. 对话模板（Dialogue Templates）

### 2.1 初次见面对话

#### 适用场景
- 新角色登场
- 势力初遇
- 相亲/联姻等特定情境

#### 结构
1. **外在观察**：用旁观者视角描写第一印象
2. **试探性对话**：双方互相试探身份/来意/立场
3. **态度确立**：通过关键台词表明关系基调

#### 示例
```
"久仰大名。"

顾长安看着眼前这个锦衣公子，嘴角微微上扬——这是他今晚第三个"久仰"了。

"阁下是？"

"在下姓秦，单名一个墨字。听闻顾兄武功高强，特来讨教。"

"讨教？"顾长安放下酒杯，"秦公子腰间这柄剑，是昆仑派的制式吧。"

秦墨面色微变。

"顾兄好眼力。"他很快恢复从容，"不错，家师正是昆仑掌门。"

"哦？那你来找我这个江湖散人讨教，是奉师命，还是..."

顾长安的目光落在秦墨袖口——那里藏着一枚暗器，造型奇特，正是三年前杀害他师兄的凶器同款。

"还是私人恩怨？"

秦墨的笑容僵了一瞬。
```

#### 变体
- **敌意初见**：一见面就剑拔弩张
- **暧昧初见**：表面客气实则试探
- **身份悬殊**：以下对上/以上对下的特殊张力

---

### 2.2 冲突对话

#### 适用场景
- 争吵/对峙
- 审讯/逼问
- 利益谈判破裂

#### 结构
1. **立场对峙**：各表诉求
2. **言语交锋**：用反问/讽刺/揭短推进
3. **情绪失控**：一方或双方情绪爆发
4. **意外转折**：第三人或突发事件打断

#### 示例
```
"你知道你弟弟做了什么吗？"

陈县令把卷宗摔在桌上，纸张散落一地。

"他杀人了？"王老员外面不改色，"杀人偿命，天经地义。"

"说得轻巧。"陈县令冷笑，"死的可是你亲家——李家的独子。"

王老员外的眼皮跳了一下。

"两家的事，自有两家解决。"

"两家？"陈县令站起身，"李家三百口人堵在县衙门口，说你王家仗势欺人，要讨个公道。你让我怎么解决？"

王老员外沉默片刻，忽然笑了。

"陈大人，你新来乍到，有些事可能不清楚。"他慢条斯理地端起茶杯，"我王家在这临安城，还没有人敢让我'给个公道'。"

门外忽然传来急促的脚步声。

"大人！不好了！"师爷冲进来，满头大汗，"李家在城外的货仓...走水了！"

王老员外吹了吹茶沫，仿佛什么都没听见。
```

#### 变体
- **冷战对话**：不说话只用眼神交锋
- **酒后吐真言**：情绪失控后的真情流露
- **审讯对话**：高压下的心理博弈

---

### 2.3 告白/表白对话

#### 适用场景
- 感情戏推进
- 关键关系确立
- 误会解除后

#### 结构
1. **氛围营造**：用环境/细节烘托情绪
2. **欲言又止**：多次铺垫延迟
3. **核心表白**：直抒心意
4. **回应/悬念**：被接受/拒绝或留白

#### 示例
```
月上中天，酒意微醺。

"其实..."沈惊鸿握着酒杯，指节泛白，"有些话，我憋了很久。"

林若雪没有说话，只是静静看着他。

"第一次见你，你从那群山贼手里救下我，明明自己也受伤了，还把最后一个馒头分给我。"

"那时候你还小。"

"我不是小孩子了。"沈惊鸿忽然抬头，直视她的眼睛，"三年前你失踪，我以为你死了。整整三年，我每天都在想，如果当时追上去..."

他的声音有些哑。

"若雪，我不做少侠了。"

"什么？"

"我找到你了，我不想再追什么宝藏、什么秘籍。"他站起身，走到她面前，单膝跪地，"你愿意...让我留在你身边吗？"

月光下，他手中握着一枚旧物——那是三年前，林若雪留给他的半块玉佩。

她认得那玉佩。另一半，还挂在她的腰间。
```

#### 变体
- **隐晦表白**：借物传情不明说
- **行动表白**：不用语言用行动证明
- **拒绝表白**：拒绝但留有余地

---

### 2.4 告别/诀别对话

#### 适用场景
- 角色下线
- 远行/出征
- 关系破裂

#### 结构
1. **不舍之情**：用细节展示依恋
2. **交代后事**：留下信物/嘱托
3. **核心台词**：点明关系/情感
4. **留白/悬念**：为后续埋线

#### 示例
```
"我要走了。"

周念恩把信放在桌上，手指在信封上停留了一瞬。

沈暮雨站在门口，没有动。

"去哪？"

"北境。"

沉默。

"为什么是北境？"沈暮雨的声音很轻，"那边在打仗。"

"我知道。"周念恩转身，终于看向她，"三年前，我爹死在北境。我答应过他，要替林家查清真相。"

"可是..."

"暮雨。"周念恩打断她，"我不会死。"

"你怎么知道？"

"因为我还欠你一壶酒。"她忽然笑了，笑得眼角有些湿，"等我还完，就回来。"

沈暮雨冲上去，把一样东西塞进她手里。

是一把匕首，刀鞘上刻着一朵小小的梅花。

"这是...？"

"我娘留给我的。"沈暮雨别过脸，"它会保佑你。"

周念恩握紧匕首，转身走向门外。

"暮雨。"

"嗯？"

"等我回来，我们一起去看梅花。"

门外，风雪正紧。
```

#### 变体
- **无言告别**：不说话只有动作
- **误会告别**：带着怨恨离去
- **生死诀别**：临终前的话别

---

### 2.5 密谋/阴谋对话

#### 适用场景
- 反派会议
- 阴谋策划
- 卧底接头

#### 结构
1. **确认身份**：暗号/信物
2. **利益交换**：各方的筹码与诉求
3. **计划部署**：具体行动安排
4. **威胁/警告**：确保忠诚

#### 示例
```
"明月几时有？"

"但愿人长久。"

暗室之中，两人相对而坐。烛火摇曳，将他们的影子投在墙上，如鬼魅般张牙舞爪。

"东西带来了？"坐在上首的黑衣人开口，声音沙哑。

桌面上，一个锦盒缓缓推出。

黑衣人打开锦盒，借着微光验看——是一枚虎符，铜绿斑驳，正是二十年前失踪的那一枚。

"不错。"他把虎符收入怀中，"三日后，按计划行事。"

"那我们的约定..."

"放心。"黑衣人冷笑，"事成之后，你父亲当年的案子，自会一笔勾销。"

下首之人面色微变："你...你怎么知道那案子..."

"我知道的事情很多。"黑衣人站起身，"比如，你为什么非要杀林家满门。比如，你和那位林夫人的真正关系。"

沉默。

良久，下首之人低下头："...明白了。"

"很好。"黑衣人的声音如同从地狱传来，"记住，你的命，捏在我手里。"

烛火忽然熄灭。
黑暗中，只剩下黑衣人的声音：
"三日后的月亮，应该很圆。"
```

#### 变体
- **醉酒真言**：酒后吐露阴谋
- **梦中呓语**：无意识透露秘密
- **三方博弈**：多方势力暗中较量

## 3. 人物弧光模板（Character Arc Templates）

### 3.1 成长弧光：普通人 → 英雄

#### 适用场景
- 主角成长线
- 草根逆袭
- 废柴崛起

#### 结构
1. **起点：平凡/劣势**（第1-10%篇幅）
   - 展示困境：能力不足、资源匮乏、被轻视
   - 核心冲突：内心渴望 vs 现实差距

2. **触发事件**（10-20%篇幅）
   - 遭遇导师/机遇/危机
   - 做出选择：接受挑战

3. **成长阶段**（20-70%篇幅）
   - 学习期：获得能力/资源
   - 试炼期：初胜 → 挫败 → 反思
   - 蜕变期：能力突破 + 心理成熟

4. **高潮：抉择时刻**（70-90%篇幅）
   - 面临终极考验
   - 用成长中获得的一切做出选择

5. **终点：新的起点**（90-100%篇幅）
   - 达成目标
   - 展示变化：言行举止、前后对比
   - 暗示新挑战

#### 示例框架
```
起点：外卖员林浩，被客户投诉，被房东催租，被女友分手。
触发：救了一个人，意外获得传承玉佩。
成长：
  - 第一次出手：帮老人讨回公道，发现自己有了内力
  - 挫败：被混混报复，差点丢掉工作
  - 反思：深夜练功，领悟"侠"的真谛
  - 蜕变：救了整个小区的孩子，成为平民英雄
高潮：面对幕后黑手，选择放过还是复仇
终点：站在高楼天台，俯瞰城市，但下一个危机已在酝酿
```

#### 变体
- **能力成长**：从无到有，从弱到强
- **心理成长**：从逃避到担当
- **地位成长**：从底层到顶层

---

### 3.2 堕落弧光：好人 → 反派

#### 适用场景
- 悲剧人物
- 反派前传
- 命运抗争

#### 结构
1. **起点：理想主义者**
   - 高尚信念：正义/公平/守护
   - 行为准则：坚持原则

2. **第一次打击**（10-30%篇幅）
   - 信念遭遇现实冲击
   - 内心动摇但仍坚持

3. **第二次打击**（30-60%篇幅）
   - 失去珍贵之物：挚友/爱人/信念
   - 开始质疑：我的坚持有意义吗？

4. **转折点**（60-80%篇幅）
   - 发现"真相"：规则是假的
   - 被利用/背叛
   - 做出错误选择

5. **终点：堕落完成**（80-100%篇幅）
   - 成为自己曾经反对的人
   - 最后的"合理性"辩护
   - 留下遗憾/悲剧伏笔

#### 示例框架
```
起点：捕快沈青天，立志当一个清官，为民请命。
第一次打击：顶头上司收受贿赂，他举报不成反被穿小鞋。
第二次打击：恩师为了自保，出卖了他的把柄。
转折点：发现当年父亲"因公殉职"是假的，真相是父亲被灭口。
终点：三年后，他成了最大的贪官。有人问他为何堕落，他说："这世道，只有比我更黑的人才能活下去。"
```

#### 变体
- **渐变堕落**：一步步滑入深渊
- **瞬间堕落**：一次重大打击彻底改变
- **被迫堕落**：为保护某人而作恶

---

### 3.3 救赎弧光：反派 → 好人

#### 适用场景
- 反派洗白
- 浪子回头
- 悲剧英雄

#### 结构
1. **起点：堕落的深渊**
   - 展示恶行及其后果
   - 建立"不可饶恕"的印象

2. **触发：善念复苏**（10-30%篇幅）
   - 遇到某个人/某件事触动内心
   - 过去的阴影 vs 现在的渴望

3. **挣扎期**（30-60%篇幅）
   - 想改变但旧势力拉扯
   - 第一次尝试救赎但失败
   - 获得新的羁绊/目标

4. **抉择时刻**（60-80%篇幅）
   - 为救赎付出代价
   - 与过去彻底决裂

5. **终点：新的身份**（80-100%篇幅）
   - 用行动证明改变
   - 接受过去但不被定义
   - 暗示成长仍在继续

#### 示例框架
```
起点：杀手"血手"张三，十年杀127人，无一失手。
触发：执行任务时，目标是恩人之女，犹豫。
挣扎：放走目标，被组织追杀；恩人却因他而死。
抉择：为保护恩人女儿，与组织同归于尽。
终点：五年后，恩人女儿成为侠女，身边有个沉默寡言的男人——没人知道他的过去，但知道他救了很多人。
```

#### 变体
- **自我救赎**：不求他人原谅
- **被救赎**：需要他人的信任才能改变
- **集体救赎**：为保护群体而牺牲自我

### 3.4 循环弧光：起点即终点

#### 适用场景
- 宿命论故事
- 悲剧循环
- 开放结局

#### 结构
1. **起点：某种选择/事件**
   - 建立初始状态
   - 埋下循环的种子

2. **发展：追寻/探索**（30-50%篇幅）
   - 主角追求某种目标
   - 过程中获得/失去

3. **揭示：发现真相**（50-70%篇幅）
   - 发现循环的存在
   - 发现起点与终点的关联

4. **抉择：打破 or 接受**（70-90%篇幅）
   - 尝试打破但失败
   - 或选择接受命运
   - 或留下悬念

5. **终点：回归起点**
   - 与开篇呼应
   - 完成循环或暗示将继续循环

#### 示例框架
```
起点：少年在海边醒来，不记得自己是谁，只记得一个名字——"林晚"。
发展：他沿着海岸线走，遇到很多人，经历很多事，逐渐拼凑出自己的过去。
揭示：原来他是三十年前的人，那场海难把他送到了未来。而他要找的人，就是三十年前害他家破人亡的凶手——现在还是个少年。
抉择：他可以杀死少年，改变未来，但他下不了手。
终点：他又回到了海边。潮汐涨落，仿佛什么都没变。但他知道，有些事，已经不同了。
```

#### 变体
- **时间循环**：同一天反复
- **命运循环**：代代重复的悲剧
- **选择循环**：不同选择通向相同结局

## 4. 情节转折模板（Plot Twist Templates）

### 4.1 身份揭露：主角是XXX

#### 适用场景
- 身世之谜揭晓
- 隐藏身份曝光
- 双重身份冲突

#### 结构
1. **铺垫**（转折前 30%篇幅）
   - 埋设线索：名字/物品/行为/他人的反应
   - 读者/其他角色产生猜测

2. **触发事件**
   - 危机/对峙/关键时刻
   - 被迫或主动揭示

3. **揭露**
   - 核心身份揭晓
   - 即时反应：震惊/不信/崩溃

4. **余波**
   - 对关系的影响
   - 新冲突的产生
   - 后续伏笔

#### 示例
```
"你到底是谁？"

张三把剑抵在黑衣人咽喉，声音冰冷。

黑衣人笑了。笑声回荡在山谷中，像某种古老的诅咒。

"你真的不记得我了？"他伸手摘下面具。

张三的瞳孔骤然收缩。

那张脸——

"怎么...怎么可能..."

那是一张和他一模一样的脸。

"我是你哥哥。"黑衣人说，"三十年前，你亲手杀死的那个哥哥。"

张三的脑海中忽然闪过无数碎片：火光、惨叫、一个和他长得一样的人倒在血泊中...

"不可能！"他嘶吼，"你死了！我亲眼看着你死的！"

"死了？"黑衣人——不，他的"哥哥"——站起身，伤口正在以肉眼可见的速度愈合。

"张三，你才是那个'死'了的人。"

"什么意思？"

"三十年前那场火里，活下来的从来不是你。"

他看着张三震惊的脸，笑容如刀：

"你以为的'记忆'，全是植入的。而我，才是真正的张三。"

远处，朝阳正在升起。

但张三觉得，这个世界从未如此黑暗。
```

#### 变体
- **盟友是XX**：看似朋友实为敌人/亲人
- **敌人是XX**：看似敌人实为亲人/恩人
- **自己不是XX**：自我认知被颠覆

### 4.2 背叛反转：盟友是敌人

#### 适用场景
- 间谍/卧底曝光
- 信任危机
- 势力重组

#### 结构
1. **信任建立**：通过事件展示"盟友"的可靠性
2. **危机时刻**：主角陷入困境
3. **背叛揭露**：盟友的真正身份/目的
4. **后果**：局势逆转，需要重新布局

#### 示例
```
"有内鬼。"

林晚棠说出这三个字时，帐篷里的气氛骤然凝固。

"你怀疑谁？"赵无极问。

林晚棠没有说话，目光扫过在场的几个人——赵无极、周长老、军师李先生、她的副手小蝶。

"我不怀疑任何人。"她说，"但内鬼一定存在。否则，敌人怎么可能每次都精准知道我们的行军路线？"

沉默。

"我来揪他出来。"赵无极站起身。

三天后，军事会议。

"我已经知道内鬼是谁了。"林晚棠站在地图前，背对着众人，"但我不想当众说出来。"

她转过身，目光落在小蝶身上。

"小蝶，你跟我来一下。"

小蝶的脸色白了一瞬，但很快恢复如常，跟着她走进内室。

门关上的那一刻，林晚棠直接出手。

小蝶的反应极快，竟然挡下了她的攻击——这反应速度，绝非普通侍女。

"你什么时候发现的？"小蝶问。

"三天前。"林晚棠说，"你在赵无极茶杯里下毒时，我就在窗外。"

"那你为什么..."

"为什么不当众揭穿？"林晚棠笑了，"因为我想知道，你背后是谁。"

她从怀里掏出一枚令牌，扔到小蝶脚边。

"这枚令牌，是从你们接头人身上搜来的。暗月宗，很大的势力啊。"

小蝶的脸色彻底变了。

"可惜，你已经没有机会告诉他们了。"
```

#### 变体
- **家人背叛**：血缘关系的阴谋
- **爱人背叛**：感情成为工具
- **偶像崩塌**：崇拜对象的真面目

### 4.3 死亡假象：角色假死

#### 适用场景
- 关键角色"死亡"
- 剧情需要重来
- 制造悬念

#### 结构
1. **铺垫**：角色处于危险中，读者担心其安危
2. **死亡事件**：通过角色视角/他人反应确认"死亡"
3. **悲痛期**：其他角色的反应
4. **反转揭露**：角色还活着
5. **余波**：揭露原因，对关系的影响

#### 示例
```
那一剑，直刺心脏。

林晚棠看着沈墨染的身体缓缓倒下，眼中满是不可置信。

"墨染...墨染！"

她扑过去，接住他的身体。血染红了她的白衣，如同三月盛放的桃花。

"为什么..."她的声音在发抖，"为什么你要替她挡这一剑..."

沈墨染的嘴唇动了动，鲜血涌出。

"因为...她是我..."

声音戛然而止。

他的手垂落。

林晚棠抱着他，在雨中坐了很久。

三天后，沈墨染被以"抗敌英雄"之名厚葬。

七天后，边境传来消息：沈家满门忠烈，唯一幸存的幼子沈墨染，其实早已秘密潜入敌营，执行死间计划。

而那个"幼子"，就是七天前下葬的那个人——真正的沈墨染，从未存在。

那具尸体，是敌国送来的替身。

真正的沈墨染，已经在敌营潜伏三年。

他杀死了那个冒名顶替的人，拿到了敌军布防图。

现在，他在等待最后的时机。

等待林晚棠来找他。

等待一个"叛徒"亲手将刀送入他胸口——只有这样，他才能洗清嫌疑，带着情报归来。

而那把刀上，已经淬好了见血封喉的毒。
```

#### 变体
- **牺牲假象**：为保护某人"死"了
- **诈降假象**：假装投敌实则卧底
- **重生假象**：以新身份归来

### 4.4 能力觉醒：隐藏能力爆发

#### 适用场景
- 主角隐藏能力展示
- 危机时刻的突破
- 设定揭示

#### 结构
1. **压制期**：能力受限，被压制
2. **触发事件**：危机/情绪波动
3. **觉醒过程**：身体/精神异变
4. **能力展示**：新能力的初次使用
5. **代价/代价伏笔**：能力的代价

#### 示例
```
"跪下。"

王二狗的膝盖不受控制地弯了下去。

对方太强了。那股威压如同实质，压得他喘不过气。

"这就是你们王家所谓的天才？"对方冷笑，"不堪一击。"

王二狗想反驳，但喉咙里只能发出嘶哑的声音。

他想站起来。

他拼命想站起来。

但他的腿在发抖，他的身体在背叛他。

"不..."他咬紧牙关，指甲深深嵌入掌心，"不要..."

脑海中，忽然有什么东西在松动。

那是一道封印。

从出生那天起就被刻在他灵魂深处的封印。

"不要打开..."一个声音在耳边响起，"打开之后，你就不是你了..."

但另一个声音更响：

"站起来！"

封印碎裂。

王二狗的眼睛在一瞬间变成了金色。

那股压在他身上的威压，如同冰雪遇到烈日，瞬间消融。

他站了起来。

"你..."对方后退一步，"你的眼睛..."

王二狗低头看着自己的手——皮肤下，有金色的纹路在流动。

"这是..."他的声音变了，低沉如龙吟，"龙血的力量？"

他抬起头，看向那个曾经不可一世的敌人。

"三年了。"他说，"三年了，我等这一天，等了三年。"

他伸出手，金色的火焰在掌心燃烧。

"现在，该我了。"
```

#### 变体
- **记忆觉醒**：解锁前世/血脉记忆
- **契约觉醒**：与某物/某人建立契约
- **诅咒觉醒**：将诅咒化为力量

### 4.5 关系逆转：敌人变盟友

#### 适用场景
- 化敌为友
- 共同敌人出现
- 利益联盟

#### 结构
1. **敌对状态**：展示双方的矛盾/仇恨
2. **冲突事件**：发生某些事动摇敌意
3. **接触机会**：被迫合作/共同困境
4. **理解建立**：发现对方的另一面
5. **关系确立**：从敌人到盟友

#### 示例
```
"你为什么救我？"

李青云看着眼前这个浑身是血的女人——三年前屠了他满门的人。

"不为什么。"林若雪靠在树上，声音虚弱，"就是...不想看着你死。"

"不想？"李青云冷笑，"三年前，你杀我全家的时候，可不是这副嘴脸。"

林若雪沉默了。

"我知道。"她说，"我没资格求你原谅。"

"你当然没有。"

"但现在..."她艰难地抬起头，"追兵马上就到。如果你杀了我，你就暴露了。"

李青云的手握紧刀柄。

他可以杀她。现在就杀。这个机会，他等了三年。

但他的手，迟迟没有动。

"为什么..."他问，"为什么三年前，你要放过我？"

林若雪愣了一下。

"你记得？"

"我记得。"李青云的声音很轻，"你那一剑，本来可以穿透我的心脏。但你偏了三寸。"

林若雪闭上眼睛。

"因为..."她的声音很轻，"你让我想起了我弟弟。"

李青云的手松开了。

"走吧。"他说。

"什么？"

"我说，走。"他转过身，"你欠我一条命。现在不是还的时候。等你伤好了，我再来找你讨。"

"你...你不杀我了？"

李青云没有回头。

"三年了。"他说，"这三年，我无时无刻不想杀你。但现在..."

他顿了顿。

"我发现，比起杀你，我更想知道真相。为什么你要灭我满门？为什么你又要放过我？"

"在我知道真相之前，你不许死。"

身后，传来林若雪压抑的哭声。

李青云没有回头。

但他的脚步，第一次没有那么沉重了。
```

#### 变体
- **被迫合作**：没有选择地成为盟友
- **不打不相识**：从对手到惺惺相惜
- **误会解除**：发现之前的敌对是误会

## 5. 伏笔模板（Foreshadow Templates）

### 5.1 语言伏笔：对话暗示

#### 适用场景
- 早期章节
- 日常对话
- 无意间的对话

#### 结构
1. **自然对话**：看似随意的闲聊
2. **关键台词**：埋入后续会应验的话
3. **当时忽略**：读者和当事人都不会在意
4. **回收**：后续章节中这句话成真

#### 示例
```
"爹，我想学剑。"

"剑？"林父放下茶杯，叹了口气，"咱们林家，世代习刀。剑是凶器，会反噬主人的。"

"我不信。"

"不信？"林父站起身，走到墙边，取下一柄布满灰尘的长剑，"这把剑，是我年轻时用的。后来我封剑了。"

"为什么？"

"因为..."林父抚摸着剑身，目光深沉，"这把剑杀过一个人。一个我本不该杀的人。"

"谁？"

林父没有回答，只是把剑重新挂回墙上。

"记住，剑是凶器。学剑之人，要么驾驭剑，要么被剑驾驭。"

多年后，当林晚棠亲手刺穿仇人心脏的那一刻，她忽然想起了父亲的话。

那把剑，就插在她脚边的泥土里。

剑柄上，刻着两个字——"林家"。

她终于明白，父亲当年说的"不该杀的人"是谁。

是林家祖先。

这把剑，沾着林家人的血。

而她，正是用这把剑，复了仇。

代价是——她再也无法控制手中的剑。
```

#### 变体
- **谶语伏笔**：预言性的话语
- **双关伏笔**：表面意思和深层意思不同
- **重复伏笔**：同一句话在不同场合重复出现

---

### 5.2 物品伏笔：关键道具

#### 适用场景
- 早期章节出现某物
- 作为礼物/战利品/日常物品
- 后续成为关键道具

#### 结构
1. **初次出现**：在不起眼的场景中出现
2. **细节描写**：描述外观/来历/特性（容易被忽略）
3. **被遗忘**：在情节中暂时消失
4. **回收**：在关键时刻发挥作用

#### 示例
```
"这是什么？"

林晚棠看着手中的玉佩，眉头微皱。

"在乱葬岗捡的。"李四说，"看成色不错，值钱。"

玉佩通体漆黑，只有指甲盖大小，背面刻着一个奇怪的符文。

"扔了吧，晦气。"

林晚棠犹豫了一下，还是把玉佩收进了怀里。

她不知道的是，那个符文，是上古封印术的标记。

而那座乱葬岗，埋葬的是千年前的封印者。

他们用生命，封印了一个即将苏醒的存在。

那块玉佩，是钥匙。

三年后，当林晚棠被逼入绝境时，她下意识地握紧了那块玉佩。

玉佩忽然发出耀眼的光芒。

符文亮起。

封印...开始松动。

而她脚下的土地，正在龟裂。

"不..."林晚棠瞪大眼睛，"这是什么..."

从裂缝中，一只巨大的眼睛缓缓睁开。

那只眼睛，和玉佩上的符文，一模一样。
```

#### 变体
- **传家宝伏笔**：家族传承的关键物品
- **战场遗物伏笔**：从敌人处缴获的物品
- **自然物品伏笔**：看似自然的物品实则不凡

---

### 5.3 环境伏笔：场景细节

#### 适用场景
- 场景描写时
- 背景设定时
- 气氛渲染时

#### 结构
1. **背景描写**：看似无关紧要的环境细节
2. **异常细节**：某些与环境格格不入的事物
3. **读者忽略**：这些细节不会引起注意
4. **回收**：这些细节成为关键信息

#### 示例
```
青云观坐落在半山腰，青砖黛瓦，古朴庄严。

林晚棠随师父上山时，正是初春时节。山路两旁，桃花开得正盛，粉白交织，如云似霞。

"好看吗？"师父问。

"好看。"林晚棠点头。

"记住这个景象。"师父说，"以后你会明白的。"

林晚棠没有多想，只当是师父的感慨。

她在青云观住了三年。

三年后，观主被害，她被迫下山。

她不知道的是，青云观的地基下，埋着一座上古大阵。桃花，是阵法的灵植，用来掩盖阵法的气息。

当她离开的那一刻，阵法启动。

三年前盛开的桃花，同一时间，全部凋零。

而山下的某个村庄，一个婴儿降生。

那个婴儿的眉心，有一朵桃花印记。

林晚棠后来才知道——

那个婴儿，是观主的转世。

而她，是唯一能唤醒他前世记忆的人。

因为她腰间的那块玉佩，正是开启前世记忆的钥匙。

师父当年让她"记住那个景象"，是因为——

那漫山的桃花，都是为一个人盛开的。

那个人，是她命中注定的劫。

也是她命中注定的缘。
```

#### 变体
- **建筑伏笔**：建筑风格暗示势力背景
- **自然异象伏笔**：反常的自然现象暗示危机
- **颜色伏笔**：特定颜色在不同场景重复出现

### 5.4 行为伏笔：反常举动

#### 适用场景
- 角色行为异常时
- 不符合人设的举动
- 隐藏的动机

#### 结构
1. **反常行为**：角色做出不符合常理的举动
2. **合理解释**：当时给出表面理由
3. **被忽视**：读者和当事人都不会深究
4. **回收**：后续揭示真正原因

#### 示例
```
"老板，来一壶酒。"

张三走进酒楼，熟练地找了个角落的位置坐下。

"好嘞！"小二热情地招呼，"客官要什么酒？"

"女儿红。"

小二愣了一下："客官，咱们这儿没有女儿红..."

"那就随便。"

张三低下头，手指无意识地在桌上画着什么。

那是一个圆圈，中间有一个点。

小二没有在意，转身去招呼其他客人。

但他没看到的是，张三的眼神，在那一瞬间，变得锐利无比。

三年后，张三以"商人"身份混入敌国。

他找到了目标——敌国宰相。

在宰相的密室里，他看到了一个图案。

和当年他在桌上画的，一模一样。

"你终于来了。"宰相转过身，"我等你三年了。"

张三的手按在腰间。

"你知道我会来？"

"当然。"宰相笑了，"因为那个图案，是我们组织的标记。你画出来的那一刻，就说明你是自己人。"

"不是。"张三说，"三年前，我是故意画给你看的。"

"什么？"

"我需要确认，你们的人是否渗透到了这座城市。"张三从怀里掏出一枚令牌，"我是朝廷密探。三年的潜伏，就是为了今天。"

他举起令牌。

"你的末日到了。"

那个当年"无意识"画出的图案，是他故意的。

是他撒下的一张网。

而宰相，只是网中的一条鱼。
```

#### 变体
- **习惯性动作伏笔**：某个习惯性动作暗示隐藏身份
- **恐惧症伏笔**：对某物的恐惧暗示过去创伤
- **选择偏好伏笔**：对某类选择的偏好暗示身份背景

## 使用指南

### 模板选择原则

| 情境 | 推荐模板 |
|------|----------|
| 新手开篇 | 开场场景 + 成长弧光 |
| 中期推进 | 冲突场景 + 情节转折 |
| 高潮设计 | 高潮场景 + 关系逆转 |
| 收尾埋伏笔 | 语言/物品伏笔 + 循环弧光 |

### 模板组合建议

- **爽文结构**：开场场景（引出主角）→ 成长弧光（逆袭过程）→ 能力觉醒（爆发时刻）→ 身份揭露（身世大白）
- **虐文结构**：初次见面（美好相遇）→ 日常场景（甜蜜时光）→ 背叛反转（信任崩塌）→ 告别对话（虐心离别）
- **悬疑结构**：环境伏笔（多处细节）→ 行为伏笔（反常举动）→ 死亡假象（误导读者）→ 真相大白（揭露身份）

### 模板变体原则

所有模板均可根据具体题材调整：
- **都市文**：背景换为城市、职场、家庭
- **仙侠文**：背景换为宗门、修仙、飞升
- **玄幻文**：背景换为异界、斗气、魔法
- **历史文**：背景换为古代朝代、战争、权谋

## 禁止

- ❌ 模板照搬不进行本地化改编
- ❌ 模板示例直接作为正文使用
- ❌ 一个情节只用单一模板（现实往往需要组合）

- ❌ 为炫技而使用模板（模板是工具，不是目的）

## 2. 风险
| 风险 | 缓解 |
|------|------|
| lsp-query 在不同 IDE/编辑器暴露形式不同 | skill 只规定 LSP 协议 (textDocument/* / workspace/*), 不假设某个具体 service |
| 宿主机没装 ripgrep | install-deps 检测并提示安装; skill 仍可降级到 grep |
| 宿主机没装任何 language server | install-deps 检测并提示; lsp-query 仍可由 IDE 暴露 |
| bash/python3 在 Windows 缺失导致 verify.sh partial fail | 与本次改动无关; CI 上跑通即可 |

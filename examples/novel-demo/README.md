# Novel 域完整流程测试

> 测试：从开书 → 大纲 → 第1-3章 → 审稿 → 润色 → 统稿 → 交付

## 测试目标

验证 novel 域从入口到产出的完整链路是否正常工作。

## 测试书籍信息

```markdown
## 测试书籍：《逆天改命》

### 基本信息
- 题材：都市重生修仙
- 风格：爽文
- 目标读者：男性向
- 预计篇幅：30章（每章3000字）

### 核心设定
- 主角：陈不凡
- 重生点：2024年，意外死亡后回到大学时代
- 金手指：前世的修仙记忆
- 核心冲突：弥补前世遗憾，踏上修仙路
```

## 测试场景

### 场景1：开书与规划

```
输入：我要写一个都市重生修仙小说，主角是普通大学生，意外获得修仙传承

预期输出：
1. 人物设定（主角、反派、配角）
2. 世界观设定（都市+修仙融合）
3. 章节大纲（第1-36章）
4. 分卷规划（3卷）
```

### 场景2：单章写作

```
输入：写第一章，主角重生回到大学第一天

预期输出：
- 章节正文 ≥2000字
- 章节结尾有悬念钩子
- 无 AI 套路化表达
- 符合人物设定
```

### 场景3：审稿评分

```
输入：审稿第1章

预期输出：
- 7维评分（情节/人物/文笔/世界观/钩子/情感/创新）
- 陷阱检测（82条）
- 问题定级（Critical/Important/Suggestion/Nit）
- 通过/不通过判定
```

### 场景4：润色去味

```
输入：润色第1章

预期输出：
- AI 套路化表达消除
- 句式重构
- 人物声音分化
- 润色报告
```

### 场景5：批量写作

```
输入：继续写到第10章

预期输出：
- 并行/串行智能调度
- 各章上下文连贯
- 伏笔埋设追踪
- 进度报告
```

# News 采编自检清单

> 内联生成结构 + 润色清单 + 34 条陷阱。采编/审稿时自检。

## 稿件结构（倒金字塔）

```
# 标题（≤20 字，含核心新闻点，无夸张词）
## 导语（5W1H，最重要事实，≤100 字）
## 正文（按重要性递减，每段一个核心信息）
## 结尾（背景/相关方回应/后续发展）
```

## 交付前自检

- [ ] 标题简洁有力，准确反映正文核心
- [ ] 导语 5W1H 齐全
- [ ] 所有事实至少两个独立信源确认
- [ ] 数据/统计数字标明来源
- [ ] 人名/机构名/时间节点准确
- [ ] 无"震惊""史上最大"等夸大词
- [ ] 区分相关性和因果性，保留不确定性措辞
- [ ] 主动语态，无 AI 套路化表达
- [ ] 每段一个核心信息，无冗余

## 红线（不满足不发稿）

| # | 陷阱 |
|---|------|
| 1 | 单一信源就发布 |
| 2 | 引用未核实社交媒体内容 |
| 3 | 传言当事实报道 |
| 4 | 过时信息当新闻 |
| 5 | 标题与正文内容不符 |
| 6 | 断章取义引用 |

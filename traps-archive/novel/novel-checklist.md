# Novel 创作自检清单

> 写后自检清单（5 维 + AI 痕迹红线）。
> **分工**：写前入口/路由/知识库/因果链预检归 `novel-protocol`（skills/novel-protocol/SKILL.md）；
> 本清单只管**写后**——AI 痕迹红线 + 5 维自检 + 返修循环。

## 写后自检（5 维）

| 维度 | 通过标准 |
|------|----------|
| **字数** | ≥2000 字 |
| **钩子** | 结尾有具体悬念（信息差/反转/冲突），非套话 |
| **AI痕迹** | 无下述套路化表达 |
| **人物一致** | 对话符合角色设定，无声音趋同 |
| **伏笔** | 新伏笔已登记到 MEMORY.md |

循环：自检发现问题 → 修正 → 再检，最多 2 轮。2 轮后仍有问题 → 提交 reviewer 判定。

## AI 痕迹红线（发现即改写）

| 陷阱 | 规避 |
|------|------|
| 眼中闪过一丝光芒 | 改成具体肢体语言 |
| 嘴角勾起一抹微笑 | 改成自然表情 |
| 深吸一口气 | 直接写行动或心理 |
| 首先/其次/最后 | 用自然叙事过渡 |
| 仿佛/似乎 | 直接陈述 |
| 不是A不是B而是C | 直接说"是C" |
| 就在这时/突然之间 | 用动作/环境变化自然过渡 |
| 万能结尾"预知后事" | 用具体悬念钩子 |

## 流水线

```
写前：novel-protocol（路由 → 装配 → 知识库绑定 → 因果链预检）
  ↓
写章
  ↓
写后：本清单自检 5 维
  ├── 通过 → 审稿（novel-evaluator 7 维评分）
  │         ├── ≥70 分 → humanizer 润色 → 更新 MEMORY → 交付
  │         └── <70 分 → 返修（最多 2 次）
  └── 不通过 → 修正（最多 2 轮）
```

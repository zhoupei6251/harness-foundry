# Token 优化策略

> **目标**：在保持质量前提下最大化成本效益，通过智能模型选择和上下文压缩实现 ~60-70% 成本降低。

## 模型选择策略

### 默认选择表

| 任务类型 | 推荐模型 | 理由 | 成本系数 |
|---------|---------|------|---------|
| 探索/搜索 | Haiku | 快速廉价，足够发现文件 | 1x |
| 简单编辑（单文件） | Haiku | 指令清晰，变更范围小 | 1x |
| 多文件实现 | Sonnet | 平衡质量与成本 | ~4x |
| 复杂架构决策 | Opus | 需要深度推理 | ~19x |
| 安全审查 | Opus | 不可遗漏漏洞 | ~19x |
| PR 代码审查 | Sonnet | 理解上下文，捕捉细节 | ~4x |
| 复杂调试 | Opus | 需保持整个系统状态 | ~19x |
| 文档编写 | Haiku | 结构简单 | 1x |

### 升级到 Opus 的条件

满足以下任一条件时，升级到 Opus：

1. **首次尝试失败** - Sonnet/Haiku 连续 2 次无法解决问题
2. **任务跨越 5+ 文件** - 涉及模块间协调
3. **架构决策** - 技术选型、模式设计
4. **安全关键代码** - 认证、加密、支付相关
5. **深度调试** - 需要追踪多层调用链

### 降级到 Haiku 的条件

满足以下条件时，降级到 Haiku：

1. **纯搜索任务** - 只需要 find/grep 结果
2. **单行修改** - 明确的小改动
3. **格式调整** - linter/格式化
4. **确认任务** - 验证前序工作的正确性

## 上下文压缩策略

### 压缩时机（应该压缩）

| 时机 | 原因 | 操作 |
|-----|------|-----|
| **研究/探索完成后** | 积累大量探索上下文 | `/compact` |
| **里程碑完成** | 阶段成果需要固化 | `/compact` |
| **失败后换方法** | 清理错误路径 | `/compact` |
| **任务切换** | 切换到无关任务 | `/clear` |
| **无关话题** | 聊完闲事后继续工作 | `/clear` |

### 不压缩的时机（不应该压缩）

| 时机 | 原因 | 操作 |
|-----|------|-----|
| **实现中途** | 会丢失变量名、文件路径、当前状态 | 等待完成 |
| **调试过程中** | 需要追踪调用栈上下文 | 等待定位完成 |
| **复杂重构进行中** | 需要理解多处代码关系 | 等待重构完成 |
| **有未保存的关键信息** | 状态未固化到文件 | 先保存状态 |

### 压缩内容优先级

按优先级保留上下文：

1. **必须保留**：未提交到文件的代码变更、文件路径
2. **优先保留**：任务目标、已完成的工作清单
3. **可以压缩**：详细的探索过程、尝试过的方法
4. **必须删除**：已被证伪的方案、不相关的探索

## 会话管理

### 命令使用指南

| 命令 | 时机 | 效果 |
|-----|------|-----|
| `/clear` | 任务切换、无关话题、阶段开始 | 重置会话，保留 CLAUDE.md |
| `/compact` | 研究完成、里程碑达成、方法失败 | 压缩历史，保留最近状态 |
| `/cost` | 长时间会话、大型任务后 | 查看 token 消耗统计 |

### 会话状态固化

长时间任务中，定期将状态保存到文件：

```
# 在关键节点执行
1. 写状态文件：`echo "## 当前进度\n- [x] 完成A\n- [ ] 进行中B" >> progress.md`
2. 完成后 /compact
3. 下次从 progress.md 恢复
```

| 设置项 | 默认值 | 推荐值 | 影响说明 |
|-------|-------|-------|---------|
| 默认模型 | opus | sonnet | ~60% 成本降低 |
| MAX_THINKING_TOKENS | 31,999 | 10,000 | ~70% 思考成本降低 |
| CLAUDE_AUTOCOMPACT_PCT_OVERRIDE | 95 | 50 | 更早压缩，更高质量输出 |

|------|------------|------------|---------|
| Haiku 4.5 | $0.80 | $4.00 | 1x |
| Sonnet 4.6 | $3.00 | $15.00 | ~4x |
| Opus 4.5 | $15.00 | $75.00 | ~19x |

## 最佳实践

1. **先用便宜模型** - 遇到复杂问题时再升级
2. **固化状态** - 关键节点保存到文件
3. **及时压缩** - 逻辑断点处主动 /compact
4. **分离探索和实现** - 探索用 Haiku，实现用 Sonnet/Opus
5. **监控成本** - 大任务定期查看 /cost
